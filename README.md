## About

**空间归档（Qzone Archive）** 是一款本地运行的开源 QQ 空间备份工具，帮助你将当前账号可访问的 QQ 空间动态、照片、视频和互动记录完整保存到本地，随时查阅、检索和离线导出。

### 它解决什么问题

QQ 空间中的历史动态与互动内容长期依赖第三方平台接口，容易因接口变更、签名过期或账号权限变化而难以完整保存。空间归档将可访问的内容整理为本地 SQLite 数据库，不依赖任何自建服务器——离线可查、可搜索、可导出，数据始终掌握在你自己手中。

### 核心能力

- **完整归档**：保存动态正文、图片、视频、点赞、评论、回复与留言的原始数据
- **相册备份**：按相册批量下载照片原图到本地，失败可单独重试，中断后自动续传
- **可靠续传**：断点续传配合频率保护（每 10 分钟最多请求 300 页），中断或限流后按上次进度继续
- **本地优先**：归档、检查点与媒体缓存全部保存在设备本地，登录凭证只在 Rust 后端内存中处理
- **检索与导出**：按内容、昵称、QQ 号搜索，按年份浏览媒体时光轴，一键生成可离线打开的 HTML 或包含本地媒体的 ZIP 离线包
- **数据可恢复**：验证密码后可从相册回收站恢复误删照片
- **隐私可控**：多账号数据隔离存储，归档与本地数据可随时删除

### 项目边界

> 归档范围受 QQ 空间接口返回结果和当前账号权限限制。程序不能恢复从未出现在互动列表中的动态，也不能绕过访问控制获取无权访问的内容。

### 项目目标

在合法授权范围内，让 QQ 空间内容能够被个人长期、完整地归档和管理——不依赖第三方服务永续在线，也不以获取无权访问的数据为代价。

## 主要功能

- **QQ 登录**：二维码登录由本机 Rust 后端处理，不要求把密码输入到本项目；桌面端还支持独立窗口网页登录。
- **动态归档**：读取 QQ 空间移动端互动列表，保存本人动态、其他用户动态和留言。
- **相册备份**：读取相册列表并批量备份照片原图到本地；可浏览照片、重试失败照片或删除本地备份，中断后从已完成照片继续。
- **内容还原**：保留动态正文、图片、视频、点赞、评论、评论回复及原始数据。
- **断点续传**：保存归档检查点，中断后可以从上次进度继续。
- **频率保护**：每 10 分钟最多请求 300 页，触发限制时按提示等待，之后按上次进度继续归档。
- **任务管理**：显示归档进度、读取页数、接口记录、写入记录和异常跳过项，并支持单独重试。
- **概览仪表盘**：查看归档统计（动态、照片、评论、赞、本地占用）、最近动态、互动排行榜和任务状态。
- **本地数据库**：使用 SQLite 保存归档数据和检查点，不依赖项目自建服务器。
- **归档浏览**：按本人动态、其他动态和留言分类浏览，支持按内容、昵称或 QQ 号搜索、分页和批量删除。
- **联系人**：查看所有互动过的联系人，按互动、点赞、评论或最近互动排序。
- **媒体查看**：按需加载图片和视频，提供图片预览、缩放和保存。
- **媒体时光轴**：按年份筛选浏览已归档媒体，支持查看原始动态。
- **HTML 导出**：支持导出全部记录或选中记录，生成可离线打开的 HTML 文件。
- **离线包导出**：把动态分类页、已备份相册、本地缓存的图片视频和结构化 `data.json` 打包为一个 ZIP，在断网设备上也能完整浏览。
- **相册回收站恢复**：验证独立密码后浏览回收站相册与照片，可将单张照片恢复到新建或已有相册，也可整体恢复相册。
- **数据管理**：不同 QQ 账号的归档数据隔离存储；可删除所选归档、清空归档，或在设置中一键删除全部本地数据（不可撤销）。
- **在线更新**：启动时自动检查发布仓库的新版本，也可在“关于”页手动检查；更新源可在构建时切换到国内 Gitee/GitCode 仓库，发现新版本后会按当前平台提供对应安装包下载入口。
- **跨平台**：支持 Windows、macOS、Linux 桌面端和 Android 移动端；发布同时产出未签名的 iOS IPA（需自行签名后侧载）。

## 安装

### 下载发布包

从当前维护仓库的 [Releases](https://gitee.com/yuchen0x1/Qzone-Archive/releases) 页面下载对应平台的安装包：

- Windows：`.exe` 安装程序
- macOS：`.dmg` 安装包（x64 / ARM64）
- Linux：`.AppImage`、`.deb` 或 `.rpm` 包；NixOS 用户可下载 `qzonearchive-nixos-*` 归档
- Android：`.apk` 安装包
- iOS：未签名 `.ipa`（需使用 AltStore、Sideloadly 等工具自行签名后侧载）

首次启动需要阅读并同意应用内的《免责声明与使用须知》。想尝鲜最新功能，可关注 [Releases](https://gitee.com/yuchen0x1/Qzone-Archive/releases) 页面中的预发布版本（如有，仅建议测试使用）。

### 从源码运行

环境要求：

- Node.js 20 或更高版本
- Rust 1.77.2 或更高版本（Tauri 2 的最低要求）
- Windows：WebView2（安装包会自动引导安装）
- macOS：Xcode Command Line Tools
- Linux：webkit2gtk-4.1、GTK3 及构建工具（见下方命令）
- Android：Android Studio、Android SDK 和 NDK

```bash
# 克隆当前维护仓库
git clone https://gitee.com/yuchen0x1/Qzone-Archive.git
cd Qzone-Archive

# Linux 桌面端构建依赖（Debian/Ubuntu）
sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev patchelf

# 安装前端依赖
npm install

# 启动桌面端开发环境
npm run tauri dev
```

## 使用方法

1. 启动应用并同意《免责声明与使用须知》。
2. 打开登录窗口，使用 QQ 二维码登录；桌面端也可以选择网页登录。登录后顶栏可一键打开当前账号的 QQ 空间页面。
3. 进入“归档任务”，点击“开始归档”。
4. 等待任务完成，或在频率保护倒计时结束后继续任务。
5. 进入“相册备份”，点击“备份全部相册”或对单个相册开始备份；失败照片可单独重试，已备份照片可随时浏览。
6. 在“归档内容”中按分类浏览、搜索、查看图片和按需播放视频，可导出或删除记录。
7. 在“相册回收站”中验证独立密码后，恢复误删的相册照片。
8. 使用“导出全部”生成离线 HTML，或使用“导出离线包”生成包含本地媒体的 ZIP 离线包。
9. 在“设置”中调整单页获取间隔（最低 2000ms）、查看隐私协议或删除所有数据；深色模式在顶栏切换，“关于”页可查看项目来源和检查更新。

## 输入与输出示例

### 输入

程序不要求导入文件。归档任务的输入来自当前登录会话和界面操作：

```text
登录方式：QQ 二维码登录
操作：归档任务 > 开始归档
归档范围：当前账号有权访问的 QQ 空间互动列表
请求间隔：设置页面中的本地配置
```

### 输出

任务完成后，界面会显示类似以下的统计信息：

```text
状态：已完成
已读取页数：42
接口记录：1,260
写入记录：318
待重试异常：0
```

归档数据保存在操作系统的应用数据目录中，包含 SQLite 数据库 `qzone-archive.sqlite3` 和已缓存媒体。导出后会生成用户选择位置的 HTML 文件，例如：

```text
QQ空间归档-本人动态-2026-08-27.html
```

上面的数字和文件名仅用于说明格式，实际结果取决于账号可见内容、网络状态和 QQ 接口返回结果。

## 数据来源与限制

归档主要基于 QQ 空间移动端互动列表接口 `mobile.qzone.qq.com/get_feeds`。该接口返回当前账号收到的互动通知，程序从中提取动态和互动内容并保存到本地；相册回收站功能使用 QQ 空间相册回收站相关接口。

因此，请注意：

- 没有被点赞或评论过、未出现在互动列表中的动态无法通过本工具恢复。
- QQ 视频地址可能带有时效性签名，过期后需要重新归档以更新地址。
- 网络中断、接口变更、限流、账号权限变化、设备故障或误操作都可能导致归档不完整。
- 登录 Cookie 仅由 Rust 后端在内存中处理，不写入控制台或日志。
- 归档过程中不要切换 QQ 客户端账号，否则可能有冻结风险。
- 所有归档内容都可能包含个人信息，请妥善保护数据库、缓存和导出文件。

## 常见问题（FAQ）

**为什么有些动态找不到？**
程序基于互动列表归档，只有被点赞或评论过的动态才会出现在互动列表中。从未被互动的动态无法恢复。

**频繁提示频率保护怎么办？**
每 10 分钟最多请求 300 页，触发后进度已保存，可等待倒计时结束继续。也可以换个时间段，或在“设置”中调大单页获取间隔（建议 3000–5000ms）。

**视频无法播放？**
QQ 视频地址带有时效签名，过期后需要重新归档以更新地址。

**图片加载失败？**
程序会优先读取本地缓存，失败时自动尝试原始地址；列表中可点击“加载失败，重试”。

**检查更新提示失败？**
更新检查默认访问 Gitee 的发布接口，也可在构建时切换到 GitHub/GitCode 等发布仓库；网络不可达时会提示失败，不影响其他功能。

**如何备份归档数据？**
应用数据目录中的 `qzone-archive.sqlite3` 和媒体缓存就是完整归档数据，可整体复制；也可以使用“导出全部”生成离线 HTML。重要资料建议定期另行备份。
